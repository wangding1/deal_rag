# 源码共同约定

## 适用范围与职责

本文件适用于 `src` 下的源码。在根目录指令基础上补充 Python 实现约定；包内职责见 `deal_pilot/AGENTS.md`，具体行为见各模块指令。

## 导入与类型

- 通过 `deal_pilot...` 包路径导入，不通过修改 `sys.path` 或复制实现来跨模块调用。
- 项目使用 Python 3.13，已有 `type` 别名和泛型函数语法；不要按更旧的 Python 版本判断这些语法无效。
- 新增函数为参数和返回值标注准确类型；配置、工具输入和结构化评分优先沿用 Pydantic 模型，避免重复定义同一契约。
- `deal_pilot/py.typed` 是包的类型标记，应保留。第三方类型不完整时局部处理，避免大范围引入 `Any` 或 `type: ignore`。

## 异步、异常与资源

- 网络、模型、对象存储、沙箱操作优先使用异步接口；必须调用同步 SDK 时评估是否会阻塞请求事件循环。
- `asyncio.run` 只用于同步入口和独立脚本，不用于异步调用链内部。
- 保持客户端、文件流和沙箱连接的生命周期清晰；关闭连接、终止沙箱与删除持久数据是不同操作。
- 缓存值可能在多个调用之间复用；不要直接修改共享返回值或缓存用户相关数据时遗漏身份维度。
- 保留取消与异常传播语义；只在有明确契约的边界转换异常，不将系统故障转换成空结果。

## 修改与验证

- 新模块先确认职责归属，再按调用链更新入口、注册表和测试；不要把全部逻辑放入 `utils`。
- 修改目录、导出名称或相对路径时核对导入、`langgraph.json`、Docker COPY、脚本和测试引用。
- 纯源码检查不能证明远程 API 或真实模型行为。测试命令从根目录执行，具体选择见根目录与模块指令。
- 新增源码目录时按其实际职责补充 `AGENTS.md`，无需为 `__pycache__` 等生成目录创建指令。
